# 中国商品住宅房产内在价值估值模型研究笔记

> 版本：v0.2（深化研究笔记 — 补充实物期权法与剩余收益法数值方法、参数估算路径表）
> 适用标的：中华人民共和国境内的商品住宅
> 文档目标：为本仓库的估值应用提供数学公式、适用边界、参数语义与权威来源依据。
> 重要原则：本文档不为任何关键数值参数（折旧率、增长率、贴现率、资本化率、空置率、续期成本、波动率 σ、续期对价 K、无风险利率 r_f、初始账面价值 Book_0、剩余收益终值 CV_N 等）提供"推荐值"或"典型值"。所有数值必须由应用使用者依据其具体标的与地区数据自行填入。

## 一、背景与中国市场特殊性

中国商品住宅与英美教科书中"freehold（永久产权）住宅"在制度层面存在根本差异，因此不能不加调整地套用 Gordon 永续增长模型。

### 1.1 70 年土地使用权与自动续期

根据《中华人民共和国民法典》第三百五十九条：

> 住宅建设用地使用权期限届满的，自动续期。续期费用的缴纳或者减免，依照法律、行政法规的规定办理。
> 非住宅建设用地使用权期限届满后的续期，依照法律规定办理。

也就是说：

- 商品住宅所占用的"住宅建设用地使用权"通常出让期限为 70 年（依《城镇国有土地使用权出让和转让暂行条例》设定）。
- 期限届满时**自动续期**，但**续期费用是否减免、按何种标准缴纳**目前尚由后续法律、行政法规规定，存在显著的不确定性。
- 因此对一栋已存在若干年的商品住宅而言，"剩余土地使用年限 N"是一个确定的法定起点，而"续期之后的价值"应被视为一项**不确定的终值（terminal value）**，可由用户用一个折扣后的续期成本/续期对价模型表达，而不是简单地假设无限期持有。

### 1.2 国家标准对估价方法的规定

国家标准《房地产估价规范》GB/T 50291-2015 是中华人民共和国境内房地产估价活动的主要技术依据，由住房城乡建设部与国家质量监督检验检疫总局联合发布，自 2015 年 12 月 1 日起实施，替代 GB/T 50291-1999。

该规范认可的主要估价方法包括：

- 比较法（市场比较法）
- 收益法（含直接资本化法、报酬资本化法等子方法）
- 成本法
- 假设开发法（剩余法）
- 路线价法、基准地价系数修正法、长期趋势法等

本笔记的"四模型并行"设计与该国家标准的方法体系保持一致：以收益法（含有限年期 DCF 与直接资本化法）为主模型，以市场比较法、成本法等为辅助校验。

### 1.3 为何"有限年期 DCF"更贴近中国语境

- 现金流期数 N 直接以"剩余土地使用年限"为自然上界，比假设无限期更符合产权事实。
- 用一个显式的"续期对价/续期后剩余权益"作为终值，可把法律不确定性显式化为一个用户可调的参数，而不是被永续假设隐匿。
- 当用户希望模拟"自动无偿续期"的乐观情形时，可将续期成本设为 0；希望模拟"按届时市场价补缴"的保守情形时，可将续期成本设为正数。所有这些都是用户输入，文档不预设。

## 二、模型一　永续模型（Gordon 增长 / 收益还原法之永续形式）

### 2.1 公式

设：

- `NOI_1`：未来第 1 年的净营业收入（Net Operating Income），单位：元/年
- `r`：投资人要求的资本化（折现）报酬率，单位：1/年
- `g`：净营业收入的长期可持续年增长率，单位：1/年，需满足 `g < r`

则永续模型估值为：

```
V_perp = NOI_1 / (r - g)
```

退化情形 `g = 0` 即为不带增长的永续资本化：`V = NOI / r`。

### 2.2 适用边界与说明

- 该模型在理论上假设标的可被永久持有并永久产生增长率为 g 的现金流，这与中国商品住宅的 70 年土地使用权制度并不完全相符。
- 但它仍然是一个有用的**上界 / 数量级 sanity check**：在"自动无偿续期、长期稳定增长"这种最乐观假设下，永续模型给出的估值可被视为内在价值的理论上限附近的参考值。
- 当 `r - g` 很小时该公式对参数高度敏感（终值放大），用户应做敏感性分析。

### 2.3 参数来源

- `NOI_1` 应由租金毛收入扣除空置、物业管理费、维修费、保险、房产税（如适用）后得到，参见本笔记第六章。
- `r`、`g` 必须由用户输入。本文档不给出推荐值。

## 三、模型二　有限年期 DCF（剩余土地使用年限上的 DCF）— 推荐主模型

### 3.1 公式

设：

- `N`：剩余土地使用年限（年）。例如：一套 2005 年取得 70 年住宅建设用地使用权的房产，估值时点为 2026 年，则 `N = 70 - (2026 - 2005) = 49`。
- `CF_t`：第 t 年的税后自由现金流（通常等于 NOI_t 扣除房产税、必要的资本性支出 CapEx 等）
- `r`：投资人要求的折现率（年化）
- `TV`：终值（terminal value），代表 N 年末时点上"住宅建设用地使用权到期 + 自动续期 − 续期对价 + 房屋残值"等净权益的现值（注意 TV 仍需折现到 0 时点）

则有限年期 DCF 估值为：

```
V_DCF = Σ_{t=1}^{N}  CF_t / (1 + r)^t   +   TV / (1 + r)^N
```

### 3.2 终值 TV 的几种用户可选构造

TV 是模型中最具中国特色的部分，文档仅描述**结构**，不给出**数值**：

- **零终值情形**：用户保守地认为续期对价等于或大于届时房屋净值，则 `TV = 0`。
- **房屋残值情形**：`TV = 残值率 × 重置成本`；其中残值率与重置成本均由用户输入，残值率不在本文档预置。
- **续期对价情形**：`TV = 续期后可剩余权益现值 − 续期对价`；续期对价可由用户参考届时土地出让金占房价比例的某个假设构造，本文档同样不预置。
- **实物期权情形**：把"是否续期"建模为一个看涨期权，详见第五章模型四。

### 3.3 适用边界

- 这是本应用推荐的**主模型**，原因是它把 70 年制度直接编码进期数 N，并把法律不确定性显式化为 TV。
- 在 Damodaran 的房地产估值章节（NYU Stern 教材 *Investment Valuation* 第 26 章 "Valuing Real Estate"）中，有限期租约 / 有限期土地使用权的资产即采用类似的"finite-horizon DCF + terminal value"结构估值。

### 3.4 参数来源

- `N` 由产权证 / 不动产权证上的土地使用权起止日期与估值时点确定。
- `CF_t` 由租金、空置、运营成本、税费的逐年预测得出，本文档不预置增长曲线。
- `r`、`TV` 均由用户输入，文档不给出推荐值。

## 四、模型三　直接资本化法（Direct Capitalization）

### 4.1 公式

设：

- `NOI`：稳态年净营业收入（元/年）
- `k`：资本化率（cap rate，1/年）

则直接资本化估值为：

```
V_cap = NOI / k
```

### 4.2 资本化率 k 的语义与可行来源（不给推荐值）

资本化率不是凭空设定的，而是市场可观测量的反映。用户在本应用中可由以下任一路径自行估算 k，但本文档不固化任何数值：

- **租售比反推**：在标的所在城市/板块取若干同类住宅的"年净租金 / 成交价"中位数，扣除非现金成本与税费后，作为 k 的市场参考。
- **同类已成交项目反推**：`k = 同类住宅 NOI / 同类住宅成交价`。
- **构建法**：`k = 无风险利率 + 流动性溢价 + 标的风险溢价 − 长期增长预期`，其中每一项均由用户输入。

参见 MBA 智库百科"资本化率"与"收益还原法"条目对该方法的中文表述。

### 4.3 适用边界

- 该方法假设 NOI 稳态、增长率隐含在 k 之中，故对持有期较短或近期 NOI 波动较大的标的不适用。
- 对存在显著剩余年限差异的中国商品住宅，应理解为"在剩余年限内若 NOI 与 k 保持稳态"的近似上界；与模型二可互为校验。

## 五、模型四　可选补充模型（至少满足"四模型"底线）

本章列出三类补充模型。应用至少实现其中之一与前述三种模型并列；其余可在后续版本中补充。

### 5.1 市场比较法（含 hedonic 调整）

### 5.1.1 公式（基本调整式）

设比较案例 i 的成交价为 `P_i`，对每个属性 j（如建筑面积、楼层、朝向、装修、楼龄、学区、地铁距离等）有调整系数 `c_{ij}`，则：

```
V_comp = (1 / m) × Σ_{i=1}^{m}  P_i × Π_{j}  (1 + c_{ij})
```

其中 m 为可比案例数。每个 `c_{ij}` 由用户根据当地市场对该属性的边际定价输入；文档不预置任何属性溢价数值。

### 5.1.2 适用边界

- 在交易活跃、可比案例充足的一二线城市核心区域最可靠。
- 对独特性强（独栋别墅、稀缺产品）或交易稀薄的标的需谨慎。
- 国家标准 GB/T 50291-2015 中"比较法"为其规范化形式。

### 5.2 成本法（折旧重置成本法）

### 5.2.1 公式

```
V_cost = L + (C_replace) × (1 − d)
```

其中：

- `L`：土地使用权评估价值（剩余年限对应）
- `C_replace`：建筑物重置完全价格（按当前建安造价重新建造同等建筑的成本）
- `d`：综合折旧率，包含物理折旧、功能折旧、外部折旧三部分；由用户输入

### 5.2.2 适用边界

- 对二手房估值通常作为下界参考。
- `d` 的具体数值与建筑年龄、维护状况、功能落后程度强相关，本文档**不给出折旧率推荐值**——这是用户必须输入的参数。
- 国家标准 GB/T 50291-2015 中"成本法"为其规范化形式。

### 5.3 实物期权法（续期作为看涨期权）

将"70 年期满后的续期"建模为一份看涨期权：标的为"续期后该房产的预期市场价值"，执行价为"届时续期对价"，到期时间为"剩余土地使用年限 N"。该期权的价值与有限年期 DCF 前 N 年现金流之和构成总价值：

```
V_real_option = Σ_{t=1}^{N} CF_t / (1 + r)^t  +  Call(S, K, σ, r_f, T)
```

#### 5.3.1 Black–Scholes–Merton 闭式解（BSM）

```
d1   = [ ln(S / K) + (r_f + σ² / 2) · T ] / (σ · √T)
d2   = d1 − σ · √T
Call = S · N(d1)  −  K · e^{−r_f · T} · N(d2)
```

变量定义（中文语义，**全部由使用者输入**）：

- `S`：续期后该房产的预期市场价值，单位：元（用户输入）
- `K`：续期对价 / 行权价，即续期一次性需缴金额，单位：元（用户输入；K 值依国家未来法规或用户所选政策情景假设）
- `σ`：资产价值的年化波动率，单位：1/√年（用户输入）
- `r_f`：无风险年化连续复利利率，单位：1/年（用户输入）
- `T`：决策可推迟年数，通常等于剩余土地使用年限 N，单位：年（用户输入）
- `N(·)`：标准正态分布累积函数（数学常量，非用户输入）

**关于不预置数值的明确承诺**：本模型所有输入参数（S, K, σ, r_f, T）均由使用者输入，本应用不预置任何数值默认。

#### 5.3.2 Cox–Ross–Rubinstein 二叉树（CRR）离散近似

当波动率非常态或希望显式建模"分阶段是否续期"的早期行权特征时，可使用 CRR 二叉树。设步数为 n（由用户选择），每一步时长 `Δt = T / n`，则：

```
u = e^{σ · √Δt}
d = 1 / u
p = (e^{r_f · Δt} − d) / (u − d)
```

其中 `u`、`d` 分别为单步上行 / 下行比例，`p` 为风险中性上行概率。期权价值由树的末端节点 `max(S_node − K, 0)` 按 `(p, 1−p)` 风险中性概率向根节点逐层倒推、每步以 `e^{−r_f · Δt}` 折现得到。当 n → ∞ 时，CRR 二叉树价值收敛于 BSM 闭式解。

#### 5.3.3 示例性符号推导（说明用，不含具体数值）

假设使用者填入 S（续期后预期市场价值）、K（续期对价）、σ（年化波动率）、r_f（无风险利率）与 T（剩余土地使用年限）：

1. 第一步计算 `d1 = [ln(S/K) + (r_f + σ²/2) · T] / (σ · √T)`，再得 `d2 = d1 − σ · √T`。
2. 第二步查标准正态分布表或调用 `erf` 函数得到 `N(d1)`、`N(d2)`。
3. 第三步代入 `Call = S · N(d1) − K · e^{−r_f · T} · N(d2)` 得到看涨期权价值。
4. 第四步把 `Call` 加到前 N 年 DCF 现金流现值之和上，得到包含续期实物期权的总估值 `V_real_option`。

本节所有公式步骤均为符号化说明；本文档与本应用均不为 S、K、σ、r_f、T 中任一项提供数值默认或建议值。

### 5.4 剩余收益法（Residual Income，Ohlson 1995 风格）

剩余收益法将"超过资本成本的超额会计收益"折现，并加回期初账面价值，得到权益价值估计。该方法在 CFA 课程权益估值章节以及 Ohlson (1995) 论文中被系统化，适用于"账面价值有意义且可逐年更新"的资产；对商品住宅可作为有限年期 DCF 与成本法之间的辅助验证。

#### 5.4.1 闭式公式

```
V_resid = Book_0
        + Σ_{t=1}^{N}  (NOI_t − r · Book_{t−1}) / (1 + r)^t
        +  CV_N / (1 + r)^N
```

变量定义（中文语义，**全部由使用者输入**）：

- `Book_0`：估值时点该住宅的初始账面价值（元；用户输入；可参考购置成本扣除已计折旧、或参考最近一次税务/会计评估值）
- `NOI_t`：第 t 年净营业收入（元/年；用户输入；与模型二中 `CF_t` 的口径需保持一致）
- `r`：与权益资本成本对应的折现率（1/年；用户输入；与模型一、二的 `r` 同义）
- `Book_{t−1}`：第 t−1 年末账面价值（元；由 Book_0 与逐年折旧、资本性支出递推得到）
- `N`：折现期数，通常取剩余土地使用年限（年；与模型二的 `N` 同义）
- `CV_N`：第 N 年末的剩余收益持续价值（continuing value，元；用户输入；保守情形下可取 0，表示 N 年末后不再产生超额收益）

#### 5.4.2 账面价值递推

商品住宅情景下，账面价值递推关系为：

```
Book_t = Book_{t−1}  −  折旧_t  +  资本性支出_t
```

其中：

- `折旧_t`：第 t 年计提的会计折旧（元；用户输入；折旧率与折旧方法本文档不预置）
- `资本性支出_t`：第 t 年新增的资本性投入（元；如大修、设备更换；用户输入）

`Book_0`、`{折旧_t}`、`{资本性支出_t}` 均由使用者输入，本应用不提供任何默认折旧曲线或资本性支出曲线。

#### 5.4.3 与 70 年土地使用权的衔接

- 折现期数 `N` 通常取估值时点的剩余土地使用年限。
- 第 N 年末是否续期、续期对价大小，与模型二中 TV 的构造一致；剩余收益法以 `CV_N` 显式承载这一不确定性：用户可取 0（不再产生超额收益），或自行构造正/负数代表续期后剩余权益与对价之差。

#### 5.4.4 示例性符号推导（说明用，不含具体数值）

假设使用者填入 `Book_0`、`{NOI_t}`（t=1..N）、`r`、`{折旧_t}`、`{资本性支出_t}` 与 `CV_N`：

1. 第一步按 `Book_t = Book_{t−1} − 折旧_t + 资本性支出_t` 递推得到 `Book_1, Book_2, ..., Book_{N−1}`。
2. 第二步逐年计算剩余收益 `RI_t = NOI_t − r · Book_{t−1}`。
3. 第三步将 `{RI_t}` 按 `(1 + r)^t` 折现并求和。
4. 第四步将 `CV_N` 按 `(1 + r)^N` 折现回 0 时点。
5. 第五步把 `Book_0`、折现剩余收益之和与折现 `CV_N` 三项相加，得到 `V_resid`。

本节所有公式步骤均为符号化说明；本文档与本应用均不为 `Book_0`、`{NOI_t}`、`r`、`{折旧_t}`、`{资本性支出_t}`、`CV_N` 中任一项提供数值默认或建议值。

## 六、参数定义与用户输入指南

本章对前面各模型出现的参数逐一定义，并描述用户在不预置数值的前提下可行的估算路径。**所有参数均为用户输入；本文档不给出任何"建议值"或"典型值"。**

| 参数 | 含义 | 单位 | 估算路径（用户自行决定数值） |
|---|---|---|---|
| `N` | 剩余土地使用年限 / 折现期数 | 年 | 不动产权证 / 国有土地使用证上的"使用权终止日期"减估值时点；通常 N = 70 − 已使用年数 |
| `NOI_1` | 未来第 1 年净营业收入 | 元/年 | 以 `(月租金 × 12) × (1 − 空置率) − 物业费 − 维修费 − 保险 − 房产税` 估算，每项均由用户输入 |
| `NOI_t` | 第 t 年净营业收入 | 元/年 | 由 `NOI_1` 与逐年增长 / 实证调整得到；增长率不预置 |
| `CF_t` | 第 t 年税后自由现金流 | 元/年 | 由 NOI_t 扣除房产税、资本性支出、必要税费得到；扣除项由用户输入 |
| `NOI` | 稳态年净营业收入（直接资本化用） | 元/年 | 取近若干年实际 NOI 的中位数或长期均值；由用户输入 |
| `r` | 折现率 / 报酬率 / 权益资本成本 | 1/年 | 构建法：`无风险利率 + 流动性溢价 + 标的风险溢价` − 长期增长预期（如有），每项由用户输入；不预置 |
| `g` | NOI 长期可持续增长率 | 1/年 | 由用户结合所在城市长期租金增长经验或宏观判断输入；不预置 |
| `k` | 资本化率 (cap rate) | 1/年 | 由租售比反推或同类成交反推（见 4.2）；不预置 |
| `TV` | 有限年期 DCF 终值 | 元 | 由用户根据所选续期假设构造（见 3.2）；不预置 |
| `d` | 综合折旧率 | 比例（无量纲） | 由用户根据建筑年龄、维护状况、功能落后程度判断；本文档**严格不给出数值**，避免误导 |
| `C_replace` | 重置完全价格 | 元 | 由用户根据当地建安造价、配套设施成本查询得到 |
| `L` | 土地使用权评估价值 | 元 | 由基准地价系数修正法或市场比较法得到，由用户输入或在应用中通过子流程估算 |
| `P_i` | 第 i 个可比案例成交价 | 元 | 由用户从同片区近期网签 / 中介公开成交数据收集 |
| `c_{ij}` | 第 i 个案例第 j 个属性的调整系数 | 比例（无量纲） | 由用户根据当地市场对该属性的边际定价输入；不预置 |
| `空置率` | 一年中房屋空置时间占比 | 比例（无量纲） | 由用户结合所在城市/板块实证数据输入 |
| `opex 比率` | 运营成本占毛租金比 | 比例（无量纲） | 由用户结合具体物业类型与管理方式输入 |
| `续期对价` | N 年末续期一次需缴金额（DCF 终值场景） | 元 | 由用户根据所选政策情景输入；不预置 |
| `S` | 续期后该房产的预期市场价值（实物期权用） | 元 | 由用户基于届时同类房产预期价值或蒙特卡洛模拟输入；不预置 |
| `K` | 续期对价 / 行权价（实物期权用） | 元 | 由用户根据所选政策情景（无偿续期 / 按市价补缴等）输入；K 值依国家未来法规，不预置 |
| `σ` | 标的价值的年化波动率（实物期权用） | 1/√年 | 由用户基于同区域历史价格波动估计（如取过去若干年成交价同比对数收益的标准差）；不预置 |
| `r_f` | 无风险年化利率（实物期权用） | 1/年 | 由用户参考估值时点国债收益率（如中长期国债到期收益率）输入；不预置 |
| `T` | 期权到期时间（实物期权用） | 年 | 通常取剩余土地使用年限 N；由用户确认 |
| `Δt` | CRR 二叉树单步时长 | 年 | `Δt = T / n`，其中步数 n 由用户选择；不预置 |
| `Book_0` | 估值时点初始账面价值（剩余收益法用） | 元 | 由用户参考购置成本扣除已计折旧、或最近一次税务/会计评估值输入；不预置 |
| `折旧_t` | 第 t 年会计折旧（剩余收益法用） | 元/年 | 由用户根据所选会计折旧方法（直线、加速等）输入；折旧率与方法本文档不预置 |
| `资本性支出_t` | 第 t 年新增资本性支出（剩余收益法用） | 元/年 | 由用户根据大修、设备更换等预算输入；不预置 |
| `CV_N` | 第 N 年末剩余收益持续价值（剩余收益法用） | 元 | 由用户根据 N 年末是否仍能产生超额收益的判断构造；保守情形可取 0；不预置 |

### 6.1 关于"不预置"的明确承诺

本应用与本文档对以下参数**严格不给出**具体数字形式的"推荐值"或"典型值"：折旧率（`d`、`折旧_t`）、增长率（`g`）、贴现率 / 报酬率（`r`）、资本化率（`k`）、空置率、续期成本 / 续期对价（含 `K`）、风险溢价、流动性溢价、终值（`TV`）、波动率（`σ`）、无风险利率（`r_f`）、初始账面价值（`Book_0`）、剩余收益持续价值（`CV_N`）、属性调整系数（`c_{ij}`）、资本性支出。这是为了避免使用者把文档/代码中的示例数字误用为真实市场预设。

任何数字最终只能由使用者根据其标的与所在市场自行输入；本应用的价值在于把这些用户输入正确地组合成上述四类（及以上）模型的估值结果。

## 七、敏感性分析与多模型交叉

建议本应用在实现层面：

- 同时输出"模型一/二/三/四"的估值，让用户横向比较。
- 对 `r`、`g`、`k`、`TV`、`σ`、`K`、`CV_N` 等关键参数提供"参数微扰 → 估值变动"的灵敏度图。
- 不对"最终估值"做加权合成的硬编码，而是让用户自行选择采纳哪一个模型或采用何种加权（加权权重也不预置）。
