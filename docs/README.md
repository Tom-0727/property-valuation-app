# 中国商品住宅房产内在价值估值 — 文档索引

本目录收录与本仓库所开发的"中国商品住宅房产内在价值估值应用"配套的研究笔记与设计文档。所有文档以中文撰写，目标读者为应用使用者、需要复核估值逻辑的同行评审者以及后续维护本仓库的工程师。

## 核心定位

- 本应用的核心价值在于"估值逻辑产出的函数"，而不在于内置任何具体的市场假设。
- 折旧率、增长率、贴现率、资本化率、空置率、续期成本等所有数值参数，一律由用户根据具体房产、所在城市与个人风险偏好填入，不在文档或代码中预置"推荐值"或"典型值"。
- 文档与代码均针对中华人民共和国境内的商品住宅（住宅建设用地使用权期限通常为 70 年）这一特定标的，不直接套用美式永续假设。

## 文档清单

- `valuation-models.md` — 估值模型研究笔记。覆盖永续模型、有限年期 DCF、直接资本化法以及若干补充模型，附公式、适用边界、参数定义与权威来源引用。
- `README.md` — 本索引文件。

## 阅读建议

1. 先阅读 `valuation-models.md` 的"背景与中国市场特殊性"章节，理解为何不能直接套用永续假设。
2. 再阅读"模型二 有限年期 DCF"章节——这是本应用推荐的主模型。
3. 其他模型（永续模型、直接资本化法、市场比较法/成本法/实物期权法/剩余收益法）作为交叉验证或上界/下界参考使用。
4. 最后阅读"参数定义与用户输入指南"，确认每个参数的含义与可行的估计方法。

## 文档原则

- 所有结论必须可追溯到权威来源（PRC 国家标准、法律法规、可查证的学术文献或可信百科条目）。
- 不在文档中对任何关键数值参数给出具体"建议数字"，只描述其语义、量纲与可行的估计路径。
- 公式使用标准数学记号；变量在首次出现时定义。
